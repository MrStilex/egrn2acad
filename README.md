# egrn2acad — выписки ЕГРН → AutoCAD

Рисует границы земельных участков из PDF-выписок ЕГРН в AutoCAD.

## Как пользоваться

1. Выделите одну или несколько выписок ЕГРН (PDF) и перетащите их на `egrn2acad.exe`.
   Или положите `egrn2acad.exe` в папку с выписками и запустите двойным щелчком — обработаются все PDF в папке.
2. Проверьте отчёт в окне: у каждого участка должно стоять `OK`.
   `!!` значит, что площадь по координатам не совпала с выпиской или координаты не найдены — такой участок проверьте вручную.
3. Рядом с выписками появится файл `EGRN_<дата_время>.scr`.
4. В AutoCAD откройте нужный чертёж, введите команду `SCRIPT` и выберите этот файл.

Каждый участок попадает на свой слой `EGRN_<кадастровый номер>`, каждый контур рисуется отдельной замкнутой полилинией
в координатах МСК-16 (в AutoCAD X = Y из выписки, Y = X из выписки). Привязки на время рисования отключаются и потом восстанавливаются.

## Сборка

Windows-версия `egrn2acad.exe` собирается автоматически в GitHub Actions (вкладка Actions → последний запуск → Artifacts).
При создании тега `v*` exe прикладывается к релизу.
