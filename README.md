# egrn2acad — выписки ЕГРН и ГПЗУ → AutoCAD

Программа берёт PDF-выписки ЕГРН и градостроительные планы (ГПЗУ) на земельные участки и делает из них файл для AutoCAD,
который сам рисует границы участков. Больше не нужно переводить PDF в Word, копировать
координаты в Excel и вставлять строки в командную строку.

## Что нужно

- Windows и AutoCAD (полная версия).
- Файл `egrn2acad.exe`. Устанавливать ничего не надо — просто положите его в удобное место,
  например на рабочий стол.
- PDF-документы на **земельные участки**:
  - выписки ЕГРН — те, что приходят из Росреестра/Роскадастра;
  - градостроительные планы (ГПЗУ).

  ЕГРН и ГПЗУ можно перетаскивать вперемешку — программа сама поймёт, где что.

## Как пользоваться

### 1. Получить файл для AutoCAD

Выделите в папке один или несколько PDF (можно сразу 10 и больше) и **перетащите их мышкой
на значок `egrn2acad.exe`**.

> Другой способ: положите `egrn2acad.exe` в папку с документами и запустите его двойным щелчком —
> программа возьмёт все PDF из этой папки.

Откроется чёрное окно с отчётом, например:

```
OK ЕГРН 16:50:060102:18629: контуров 4, площадь по координатам 42516.6 м² (ЕГРН 42517)
OK ЕГРН 16:50:060102:3860: контуров 1, площадь по координатам 5215.3 м² (ЕГРН 5215)
OK ГПЗУ 16:50:060102:18626: контуров 1, площадь по координатам 23873.7 м² (ГПЗУ 23874)
!! письмо.pdf: не похоже на выписку ЕГРН или ГПЗУ — пропущен

Готово: C:\...\EGRN_2026-10-05_133002.scr
```

Рядом с PDF появится файл `EGRN_<дата>_<время>.scr`. Нажмите Enter, чтобы закрыть окно.

### 2. Проверить отчёт

Программа сама считает площадь участка по координатам и сравнивает её с площадью, указанной в самом документе.

| В начале строки | Что значит | Что делать |
|---|---|---|
| `OK` | Координаты прочитаны верно, площадь совпала | Ничего, всё хорошо |
| `!!` … НЕ СОВПАДАЕТ | Площадь по координатам отличается от документа | Участок нарисуется, но сверьте его с документом вручную |
| `!!` … не найдены координаты | В документе не нашлись координаты границ | Участок не нарисуется — см. «Если что-то не так» |
| `!!` … не похоже на выписку ЕГРН или ГПЗУ | Это другой документ | Файл пропущен, остальные обработаны |

### 3. Нарисовать в AutoCAD

1. Откройте чертёж, в который нужно добавить участки (новый или уже существующий в МСК-16).
2. Введите команду **`SCRIPT`** и нажмите Enter.
3. Выберите созданный файл `EGRN_….scr` → **Открыть**.

AutoCAD сам нарисует все участки и покажет их на экране целиком.

## Что получится в чертеже

- Каждый участок лежит на **своём слое**: `EGRN_<кадастровый номер>` для выписок ЕГРН
  и `GPZU_<кадастровый номер>` для ГПЗУ, например `EGRN_16-50-060102-18629`.
  Если перетащить ЕГРН и ГПЗУ на один и тот же участок, получатся два слоя — их удобно сравнить. Так участок легко найти, скрыть, заморозить или перекрасить.
- Каждый контур — **отдельная замкнутая полилиния**. Если участок многоконтурный
  (например, из 4 частей), будет 4 полилинии на одном слое.
- Координаты — **как в документе, в системе МСК-16**. Поэтому соседние участки из разных документов
  сразу встают рядом, а участки ложатся на уже существующую подоснову в той же системе.
- Рисуются **только границы** — без подписей точек и номеров.

Документы можно добавлять постепенно: сделайте новый `.scr` из новых PDF и запустите его в том же чертеже.

## Если что-то не так

**Windows пишет «Windows защитил ваш компьютер» и не запускает программу.**
Это обычное предупреждение для программ без цифровой подписи. Нажмите
**«Подробнее» → «Выполнить в любом случае»**. Достаточно один раз.

**Антивирус ругается на `egrn2acad.exe`.**
Иногда антивирусы ошибочно реагируют на такие программы. Добавьте файл в исключения
или напишите тому, кто передал вам программу.

**Программа долго открывается.**
Первый запуск может занять 5–15 секунд — это нормально.

**«не найдены координаты границ участка».**
Возможные причины:
- это выписка не на земельный участок (например, на здание или помещение);
- PDF — это скан или фото, а не исходный электронный документ (в нём нельзя выделить текст);
- в выписке действительно нет координат («Сведения о характерных точках границы» отсутствуют —
  у участка не установлены границы).

**«площадь … НЕ СОВПАДАЕТ».**
Откройте документ и сравните точки с нарисованным участком: в выписке ЕГРН это раздел 3.2,
в ГПЗУ — таблица «Описание границ земельного участка» на первой странице.
Если видите, что участок нарисован неправильно, — сообщите и приложите этот PDF.

**После SCRIPT на экране ничего не видно.**
Введите команду `ZOOM`, затем `E` (показать всё). Если участки далеко от остального чертежа —
значит, чертёж не в системе МСК-16.

**Нарисовалось лишнее или дважды.**
Если запустить один и тот же `.scr` два раза, участки нарисуются поверх друг друга.
Чтобы удалить участок целиком, удалите его слой командой `LAYDEL` и выберите слой участка (`EGRN_…` или `GPZU_…`).

**Привязки (объектная привязка) перестали работать.**
Программа выключает их на время рисования и потом включает обратно. Если AutoCAD прервал скрипт
на середине, включите привязки вручную клавишей **F3**.

## Для разработчика

- Код: [egrn2acad.py](egrn2acad.py) (Python, `pdfplumber`). Тип документа — по тексту первой страницы.
  ЕГРН: координаты из раздела 3.2 (может быть на нескольких листах).
  ГПЗУ: таблица между «Описание границ земельного участка» и «Кадастровый номер земельного участка» (стр. 1–2).
  Новый контур — когда снова встречается первая точка текущего контура.
- В `.scr` порядок координат `Y,X` (в ЕГРН X — север, в AutoCAD X — восток); кодировка cp1251, переводы строк CRLF.
- Проверка: площадь по Гауссу против площади из документа, допуск `max(1 м², 0.1%)`.
- Сборка Windows-версии — GitHub Actions ([build.yml](.github/workflows/build.yml)):
  каждый push в `main` → Actions → Artifacts; тег `v*` → exe в Releases.
- Запуск из исходников: `pip install -r requirements.txt && python egrn2acad.py выписка1.pdf выписка2.pdf`.
